N2 - Atividade 01: Primeiros passos com JavaScript

Liguei um arquivo .js na página e fiz um botão mostrar uma mensagem quando é clicado.

O que aprendi: usar o querySelector para pegar o botão e o addEventListener para saber quando ele foi clicado.

Atividade 08: Itens de redes de computadores

Fiz uma página com os principais itens de uma rede, e cada um tem uma página explicando o que ele faz.

O que aprendi: organizar o CSS, usar grid para deixar os itens lado a lado e fazer links entre as páginas.

N1 - Atividade 05: Galeria de imagens

Fiz uma página com imagens de placas de vídeo e de gabinetes gamer, separadas em grupos.

O que aprendi: colocar imagens com a tag img, usar o alt para descrever a imagem e agrupar conteúdo com fieldset e legend.
